# 应用布局适配

虚拟投放时，如果画面两侧留空、文字或栏目显示不全，在“背屏 → 投放与显示 → 应用布局适配”搜索对应的 App，开启适配并重新投放。可以先用默认的 200 DPI；如果效果不合适，关闭适配后重新投放即可。画面正常的 App 可保留标准布局。

## 调整内容大小

开启适配后，点该 App 的“布局大小”。范围为 72–640 DPI：数值越小，内容越小，屏幕能显示的信息越多。恢复默认使用 200 DPI；自动化链接中明确指定的 `dpi` 优先。关闭适配只暂停使用该 App 的自定义 DPI，不清除保存值。修改从下一次虚拟投放生效，不打断当前会话。

布局适配会尝试让 App 按虚拟屏的方向、宽高比和窗口尺寸重新排版。系统无法放宽窗口限制时，仍可调整布局大小。此功能只影响虚拟投放，不修改系统显示设置，也不是使用背屏键盘的前提。主屏选择物理投放后，虚拟投放的偏好仍可调整，也会用于从通知和背屏壁纸打开应用。

## 批量管理

搜索框下的“全部开启”或“全部关闭”影响当前所有可投放 App，即使列表已筛选。批量操作保留已保存的 DPI，之后仍可逐个调整。新装 App 默认使用标准布局。
