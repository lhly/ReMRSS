# 投放中的紧凑通知

虚拟投放期间，符合通知总开关、应用选择、勿扰和倒扣条件的通知，会显示为摄像头安全区顶部的紧凑胶囊。图标、标题和一行摘要覆盖在原投放画面上，不缩小或移动画面，不启动通知 Activity，也不暂停投放或切换背屏任务。如果背屏已熄灭且原投放仍在，新的消息会尝试仅唤醒背屏，以便在原应用上显示胶囊；主屏和全局常亮设置不变。

全屏通知或充电页面显示期间主动开始投放，会结束旧提示并撤销其归还操作；旧提示到期不会停止新投放。后续新通知和充电提示继续按当前投放模式显示。

胶囊按“通知显示时长”自动收起，最多显示两分钟；无障碍建议时长可能延长显示。设置“全屏通知不自动关闭”不改变胶囊时长。连续通知直接替换当前内容并重新计时，不排队展示已经过期的消息。标题、正文的隐私设置和通知暗夜模式继续生效，常规模式跟随系统深浅色。

## 选择点按行为

从 V4.0.0-rc.6 起，在「通知 → 通知规则 → 点击通知」选一种行为。新通知到达时始终不会自动切换 App。

| 选择 | 背屏空闲时点全屏通知 | 已有虚拟投放时点胶囊 |
| --- | --- | --- |
| 在主屏打开应用 | 在主屏打开来源应用 | 在主屏打开来源应用 |
| 在背屏打开 | 在背屏尝试打开通知 | 应用已在背屏前台时只收起胶囊，否则尝试切换 |
| 仅背屏空闲时在背屏打开 | 在背屏尝试打开通知 | 只收起胶囊 |
| 仅关闭背屏提醒 | 收起全屏提醒 | 只收起胶囊 |

旧版“在背屏打开”保留为空闲时才打开。想让主动点按切换已有投放，请选“在背屏打开”。选择打开行为时会检查需要的权限与服务。切换到其他应用遇到阻碍时，原投放保持运行，并提示原因。在锁屏时打开微信首页仍需单独授权，不跳到聊天详情，也不点亮或解锁主屏。

胶囊范围内从按下到抬起的完整手势不会穿透下方 App。拖动或多指不会误触发通知，通知到期或替换也不会把仍按住的手指转成 App 点击。打开投放菜单、切换显示范围、暂停或关闭屏幕时，胶囊隐藏；恢复可见时，只显示仍未过期的最新通知。结束投放后清除内容和定时任务。

物理直投仍用全屏提醒。若背屏已有应用，选择“仅背屏空闲时在背屏打开”会只收起提醒；选择“在背屏打开”会提示先退出当前页面。虚拟投放期间插电也使用胶囊，显示充电状态和当前电量，8 秒自动消失或点按关闭；充电常亮只影响全屏充电动画，不会让胶囊长期覆盖投放。重复同一次插电不会重新弹出，拔线仅清理仍显示的充电提示，不关闭后来的消息。
